NO AI INSIDE

Sheet Studio doesn't use AI. I coded it myself in JavaScript. It reads your description for the words and phrases I taught it (like lessons, due dates, stars, or a $5,000 budget), turns each one into a build command, and runs those commands to assemble the workbook. The build log shows every command it ran.

Spreadsheets I've built

Sheet Studio borrows its style from real spreadsheets I've designed for courses. Both follow the same rules: the cream cells are the only ones you touch, everything else is automatic, and the important numbers sit right at the top.

Course time calculator
Higher education · faculty and instructional designers
  • Numbered setup sections: course details, exams, module goals, progress
  • Pick an activity type and enter an amount; minutes calculate themselves from a rate table
  • Fourteen module tabs roll up into one overview with direct and indirect minutes
  • Status turns green when the course meets its required time
Gamified lesson tracker
Law school course · students
  • A How to Use tab with step-by-step directions
  • Choose a lesson from a dropdown; its link, summary, and minutes fill in
  • A star bar across the top lights up as submitted minutes add up
  • Rows turn green when submitted, and repeat lessons are flagged as redos
